# 🎓 Student Life Manager

A web application designed to help university students manage their academic and personal activities in one place.

Student Life Manager brings together essential tools for organizing schedules, tracking finances, managing study goals, and planning academic performance.

## 🌐 Live Demo

[Open Student Life Manager](https://rawinan-txt.github.io/student-life-manager/)

## ✨ Features

- **Dashboard** — View an overview of daily activities and progress.
- **Schedule Management** — Organize classes, tasks, exams, and important events.
- **Finance Tracker** — Record income and expenses, manage categories, and monitor budgets.
- **Study Plans** — Set study goals, track study sessions, and monitor progress.
- **GPA Planner** — Calculate GPA and plan target academic performance.

## 🛠️ Built With

- JavaScript
- Browser Local Storage

## 🚀 Getting Started

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Start using the application.

No additional installation is required for the current standalone version.

## 📌 Notes
